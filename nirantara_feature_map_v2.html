⚡
Zero hardcoding. Zero keyword matching. Zero fixed thresholds. Every crisis detection, sentiment analysis, cycle prediction, risk score, and JITAI trigger is driven by trained ML models or NLP classifiers. Rule-based fallbacks exist only for network failure and are temporary.
ML/NLP Models Required 7 models total — all run locally on RTX 3050 + 16GB RAM
sentinet/suicidality
Crisis Detection
● High Complexity
⏱ Download: ~1.5GB · First run: 5–10 min warm-up
Fine-tuned on mental health text. Returns crisis_probability: 0–1. Translates Tamil/Tanglish via Sarvam before inference.
keyword list: "suicide", "kill myself"
→ NLP probability: context-aware scoring
ai4bharat/indic-bert
Sentiment Analysis
● Medium Complexity
⏱ Download: ~500MB · Fine-tune: optional
Trained on Indian languages including Tamil, Tanglish, code-mixed. Understands emotional context in Indian linguistic patterns.
keyword counting: neg_count > 2
→ Semantic score: understands meaning
j-hartmann/emotion-english-distilroberta-base
Emotion Detection
● Medium Complexity
⏱ Download: ~300MB · Ready to use
7-class emotion: joy, sadness, anger, fear, surprise, disgust, neutral. Tamil/Tanglish translated first via Sarvam.
not detected previously
→ 7-class emotion with confidence score
Personalized LSTM (PyTorch, custom)
Cycle Phase Prediction
● High Complexity
⏱ Train per user: ~30 sec · Min 3 cycles needed
Trained on each woman's own period history. Outputs vulnerability_score: 0–1. Handles PCOS (35–90 day cycles), postpartum, perimenopause. Population fallback before 3 cycles.
if cycle_day >= 22: high_risk = True
→ Personalized curve: her pattern, her window
XGBoost (14 features, custom trained)
Risk Score Prediction
● High Complexity
⏱ Train once: ~5 min on RTX 3050 (gpu_hist) · Target: 85%+ accuracy
14-feature multi-signal fusion. SHAP Shapley values for explainability. Top 3 human-readable factors per prediction. Classes: low / moderate / high / crisis.
risk += 0.35 if mood < 2 (arithmetic)
→ XGBoost: trained on PHQ-9 + DEPTWEET
Personalized XGBoost (custom, per user)
JITAI Receptivity
● High Complexity
⏱ Train per user: ~5 sec · Min 5 responses needed
Learns when THIS user responds positively to interventions. Features: time of day, day of week, risk score, cycle vulnerability, steps deviation. Evening-biased population fallback.
if hour == 19 and mood < 2: send_notification
→ Per-user receptivity model from response history
the NVIDIA model chain via Ollama (CUDA · RTX 3050)
Context-Aware Generative Chat
● Medium Complexity
⏱ Download: ~4GB · Response: 2–5 sec on RTX 3050 · Fully local
Generates warm, contextually appropriate Tamil/Tanglish/English responses. Receives cycle phase, mood score, risk level, detected emotion as context. Never formulaic.
template: "I understand you're feeling down. Try this breathing exercise."
→ The LLM generates unique response every time, culturally sensitive, language-matched

Risk Level Scale XGBoost output → clinical action
Score: 0.0 – 0.29
Low
Standard passive monitoring. No JITAI unless engagement drops.
Score: 0.30 – 0.59
Moderate
Increased JITAI frequency. Gentle nudges. No clinician alert.
Score: 0.60 – 0.79
High
Clinician alert triggered. CBT/grounding interventions. Daily monitoring.
Score: 0.80 – 1.00
Crisis
Immediate escalation. Zero cooldown. NIMHANS helpline. Clinician instant alert.
